# Lumen

A quiet paper-journal for daily rituals. Name something you want to keep, mark the days you do it, and watch the week fill in.

## What it does

- **Week** and **month** grids for every ritual
- Streaks, plus a perfect-day run when every mark is kept
- **Path** — chapters of light, a weekly pact, and seals earned by showing up
- Data stays on this device (no account)

## Stack

TanStack Start, React, Tailwind CSS, and Zustand.

## Develop

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```
